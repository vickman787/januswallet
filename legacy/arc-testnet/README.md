# Archived Arc Testnet UI

These unused components came with the original export. They depend on a removed
JanusSplitter configuration and are not imported by the active mainnet app.
They are preserved for reference outside the active TypeScript compilation.
Do not wire them into the mainnet app without reconciling network, ABI,
settlement, QR and simulation behavior. The exact originals remain in the
`arc-studio-baseline` Git tag.
